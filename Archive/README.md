# Historical research archive

The Legacy directory preserves earlier papers, simulations,
visualizations, images and experimental programs.

These materials document the development of the framework.
They may contain preliminary hypotheses, superseded numerical
models or research interpretations.

They are not automatically covered by the v2.7 Lean audit.

Their relocation preserves original Git blob identities,
except that generated Python bytecode has been untracked.

Some historical links and standalone scripts may require
their original directory context.

The pre-consolidation repository remains available in Git
history at commit 178a78f09608c1a2158e6a7ce64868ec4207b909.
